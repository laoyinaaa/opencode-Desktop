OpenCode 桌面 便携版

适用系统
- Windows 10 或 Windows 11，64 位。
- 不需要安装 Python。
- 已内置 OpenCode CLI，不需要单独安装。
- OpenCode 需要联网访问模型服务。

开始使用
1. 将压缩包完整解压到普通文件夹，不要直接在压缩包内运行。
2. 双击 OpenCodeDesktop.exe。
3. 如果提示缺少 Microsoft Edge WebView2 Runtime，选择“是”自动安装。
4. 在欢迎界面点击“登录 OpenCode”，完成自己的账户或 API 提供商登录。
5. 选择或输入项目文件夹，点击“开始使用”。

使用提示
- 点击输入框左侧的“图片”可以添加图片，也可以直接粘贴或拖入图片。
- 点击“文件”可以选择任意本地文件，发送时会把绝对路径交给 Agent 读取；文件本身不会上传。
- 模型正在工作时仍可继续发送，新消息会显示在输入框上方排队，并在当前任务的下一分段插入执行，而不是等整个任务结束。
- 队列支持暂停、继续和清空。点击“停止生成”会自动暂停当前会话的队列，需要手动点击“继续”才会插入。
- 单个会话最多排队 20 条，附件总量最多 64 MB。插入中的首条消息不能移除，此时清空按钮会禁用。
- 队列首条发送失败时会保留该消息，可以重试或移除；失败消息未处理前，后续消息不会发送。
- 切换项目、重启服务或更新 OpenCode CLI 前会提示队列将被清空，可以取消操作。
- 输入框以 / 开头会弹出 OpenCode 命令与技能列表，支持键盘选择；右键左侧会话可以重命名。
- 回车发送消息，Ctrl+Enter 换行。
- 任务完成或失败时，会通过 Windows 系统通知提醒。
- 每条回答和每个分段都会显示耗时；生成过程中实时更新，多分段回答还会显示本轮总耗时。
- 模型选择器旁会显示上下文的已用 / 总量和百分比，悬停可查看完整 token；切换模型后按新模型的上限重算。
- 设置中可以开启“自动允许权限”。开启后 OpenCode 的工具权限请求会自动允许，请只在信任当前项目时开启。
- 图片和提示词会发送给你选择的模型提供商，请注意内容隐私。
- 排队消息只保存在当前应用内，关闭应用或重启服务后未插入的排队消息会丢失。

关于登录
- 压缩包不包含任何人的账号、API Key 或登录凭据。
- 每个使用者必须使用自己的 OpenCode 账户或自己的模型 API 配置。
- 登录按钮消失说明已经检测到当前 Windows 用户存在 OpenCode 登录配置。
- 也可以在设置中点击“登录 / 切换 OpenCode 账户”。
- 登录窗口关闭后回到主窗口；如果本地服务已经在运行，请保存设置或重启应用。

数据位置
- 桌面设置：%APPDATA%\opencode-desktop\config.json
- 服务日志：%APPDATA%\opencode-desktop\serve.log
- 启动错误：%APPDATA%\opencode-desktop\desktop.log
- OpenCode 登录信息：%USERPROFILE%\.local\share\opencode\auth.json
- 便携版只把程序放在当前文件夹，账户、会话和日志仍保存在当前 Windows 用户目录。

更新说明
- 内置 OpenCode CLI 不通过应用内按钮单独升级，CLI 更新随新的桌面包发布。
- 需要更新时，完整解压新版便携包并替换旧程序目录。

故障排查
- 提示缺少 WebView2 且自动安装失败：手动运行 webview2\MicrosoftEdgeWebView2Setup.exe，完成后重新打开应用。
- 提示未找到 OpenCode CLI：确认 cli\opencode.exe 存在，且没有杀毒软件隔离该文件。
- 无法启动：查看 %APPDATA%\opencode-desktop\desktop.log 和 serve.log。
- Windows SmartScreen 可能提示未知发布者，因为程序未使用商业代码签名证书。
- 如果杀毒软件拦截，请先确认文件来源可信，再将整个程序目录加入信任。
